# Aplikasi Manajemen Peserta Praktikum

Praktikum Pemrograman Web Modul 06 - React Dasar (React + JavaScript + Vite).

## Cara Menjalankan

1. Buka terminal pada folder proyek.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`, lalu buka alamat yang muncul di terminal.
4. Sebelum dikumpulkan, jalankan `npm run build` untuk memastikan build berhasil.

Data disimpan di state selama aplikasi berjalan. Reload halaman mengembalikan data awal.
